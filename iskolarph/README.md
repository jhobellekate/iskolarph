# IskolarPH
Open `index.html` in a browser (or run a local server, e.g. `python -m http.server`).
Files: index.html, css/style.css, js/script.js
Saved scholarships and tracker progress are stored in localStorage (this browser only).
Scholarship records are in the `scholarships` array at the top of js/script.js; always confirm with the official source.
