# IskolarPH
Open `index.html` in a browser (or run a local server, e.g. `python -m http.server`).
The site includes scholarship search and tracking, an eligibility matcher, exam prep (`exam.html` with `js/examdata.js` and `js/exam.js`), and a program/university directory (`programs.html` with `js/programdata.js` and `js/programs.js`).
Saved scholarships and tracker progress are stored in localStorage (this browser only).
Scholarship records are in the `scholarships` array in `js/data.js`; always confirm with the official source.
