# IskolarPH (React + Vite + Tailwind CSS)

A scholarship discovery and tracking app for students planning programs, deadlines, and exam prep in the Philippines.

## Run locally

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # production build in dist/

## Notes

- Saved scholarships, folder progress, and exam progress live in the browser's localStorage.
- Data lives in `src/data/`: `scholarships.js`, `programs.js`, `exam.js`, and `personas.js`.
- The app helps users compare scholarships, filter programs, track document readiness, and review sample exam topics.
