# IskolarPH (React + Vite + Tailwind CSS)

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # production build in dist/

Saved scholarships, folder progress and exam progress live in the browser's localStorage.
Data lives in `src/data/`: `scholarships.js` (290 records), `programs.js`, `exam.js`, `personas.js`.
